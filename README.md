# 📊 Sample Superstore Sales Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive **Sales & Profit Analysis Dashboard** built in **Microsoft Power BI** using the Sample Superstore dataset.

The dashboard transforms raw sales data into meaningful business insights using KPI cards, charts, filters, and interactive visualizations.

## 🎯 Project Objectives

- Analyze overall sales and profit performance
- Understand sales performance across categories and regions
- Identify high-performing customer segments
- Analyze sales by shipping mode
- Compare product sub-categories
- Identify the top-performing cities by sales
- Calculate and monitor profit margin

## 📈 Dashboard KPIs

- **Total Profit:** 286.40K
- **Total Sales:** 2.30M
- **Total Quantity:** 38K
- **Profit Margin:** 12.47%

## 📊 Dashboard Features

### Sales Analysis
- Total Sales by Category
- Total Sales by Region
- Total Sales by Customer Segment
- Total Sales by Sub-Category
- Top 10 Cities by Sales

### Profit Analysis
- Total Profit by Category
- Overall Profit Margin

### Additional Analysis
- Sales by Ship Mode
- Interactive Segment Filter
- Interactive Region Filter
- KPI Cards for quick performance monitoring

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## 🔄 Data Preparation

The dataset was cleaned and transformed using **Power Query** before creating the dashboard. Data preparation was performed to ensure the data was accurate and suitable for analysis and visualization.

## 💡 Key Insights

- Technology is one of the strongest-performing categories by sales.
- The West region records the highest sales among the displayed regions.
- Consumer is the highest-performing customer segment by sales.
- Phones and Chairs are among the leading sub-categories by sales.
- The dashboard provides interactive filters for comparing different regions and customer segments.
